开通免费云同步

网站已准备好同步代码，但需先创建你自己的Supabase免费项目。启用前仍使用当前浏览器的本地资料。

  1. 打开Supabase控制台，可用GitHub登录。创建Free组织和项目，名称可填 engineering-notebook，保存好自己设置的数据库密码，不用发给其他人。不选择付费方案。
  2. 进入项目的 SQL Editor，打开数据库初始化脚本，复制全部内容到SQL Editor并运行。脚本创建按账号隔离的资料表和私有文件桶。
  3. 进入 Authentication → Users → Add user → Create new user，添加自己用于学习网站登录的邮箱和新密码，选择确认邮箱。然后在 Authentication 的用户注册设置中关闭新用户自助注册（Allow new users to sign up）。网站没有公开注册入口，也不依赖发送注册邮件。
  4. 在项目设置的 API / API Keys 页面复制项目URL与 publishable key（旧项目也可用 anon）。这两个值用于公开网页连接数据库。不要提供 secret、service_role、数据库密码或个人access token。
  5. 将项目URL与公开密钥交给维护者，填写仓库 public/sync-config.json 的 url 与 key 后重新构建发布。公开密钥不提供个人资料读取权限；实际权限由登录和行级安全策略控制。
  6. 发布后在网站登录你的学习账号。点击“迁移本机数据”，将当前浏览器的笔记、收藏和文件复制到云端；相同编号会跳过。换一台电脑登录同一账号，验证笔记和文件均可读取。本机数据会保留。

同步方式

登录后修改直接写入云端，每30秒及切回页面时读取新数据。未登录时继续使用本地模式。网络错误时不会把失败的云端写入假装保存到本地；请保留编辑内容，恢复网络后重试。同时编辑同一篇笔记时，过期版本会被拒绝，需要刷新并重新编辑。

文件单个上限50MB；免费空间与流量以Supabase当前控制台显示为准。项目可能因低活跃暂停，需要到控制台恢复。文件上传、资料保存是两个步骤；清理失败会明确提示。
